# Projeto Final PWEB - Kanban de Estudos

Este projeto é uma aplicação web de Kanban para organização de conteúdos de estudo.

Planejamento de Estudos.

Funcionalidades

- Cadastro de conteúdos de estudo
- Edição de conteúdos
- Exclusão de conteúdos
- Organização em três colunas
- Arrastar e soltar entre colunas
- Filtro de busca
- Salvamento dos dados no localStorage
- Layout responsivo

Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- localStorage
